# P1 학습 경로

**단계별 최신 기준:** [로드맵](../../docs/production/ROADMAP.md#phase-plan) · [계획/구현 차이](../../docs/production/PHASE_ALIGNMENT.md). 새 규칙을 검증한 P0에서 시작한다. 룰렛·신화·강화·스킬 확장과 사냥/미션/통계/불멸/2배속 후보는 로드맵의 TASK 연결에 따라 세분화한다. 후보 범위를 자동 확정하지 않으며, 후속 10배수 보스·즉시 한도 패배·경로·해상도 회귀를 완료 조건에 포함한다.

[학습 홈](../README.md) · [운영 규칙](../WORKFLOW.md) · [P0 초기화·재시작 기준](../../docs/production/P0_RESET.md)

P0를 바탕으로 전투·경제·콘텐츠·UI를 확장한다. 기존 역할의 연속 작업은 연결하되 저장·설정·아트·성능 등 미배정 작업의 담당을 임의로 정하지 않는다. 범위의 원본은 [로드맵](../../docs/production/ROADMAP.md)과 [작업 보드](../../docs/production/BOARD.md)다.

## 제작·개발 기준점

| 항목 | 참고용 제작 | 실제 학습 개발 |
|---|---|---|
| 상태 | Planned — 상세 수업 미작성 | Planned — 시작 전 |
| 출발 조건 | 검증된 참고 P0 통합 결과 | 직접 완성하고 검증한 실제 P0 통합 결과 |
| 출발 커밋 전체 SHA | 미생성 | 미생성 |
| A / B 브랜치 | 미생성 / 미생성 | 미생성 / 미생성 |
| 통합 브랜치·완료 SHA | 미생성 | 미생성 |
| 검증 기록·태그 | 없음 | 없음 |

## 진행 순서

1. [공통 준비](COMMON.md)에서 이전 결과·추가 범위·공통 API 변경·역할을 확정한다.
2. [A 경로](A/README.md)와 [B 경로](B/README.md)의 수업을 제작·재현한다.
3. [통합 검수](INTEGRATION.md)에서 이전 기능 회귀와 새 기능을 확인한다.
4. 다음 마일스톤도 같은 폴더 구조를 사용하고 각 과정의 자기 통합 SHA에서 이어간다.

이전 P0 참고 완성본을 실제 개발 브랜치에 덮어써 출발점을 맞추지 않는다. 두 과정의 커밋은 별도로 기록하고 동작·API·데이터 호환성을 대조한다.
