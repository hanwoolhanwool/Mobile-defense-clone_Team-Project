## 현재 연결할 범위

[B 구현 설계](../../../docs/technical/IMPLEMENTATION_B.md)의 P1 후속 범위를 따른다.

| 상위 작업 | 제작할 학습 내용 | A와 연결할 경계 |
|---|---|---|
| TASK-ECON-02 | 확인된 룰렛·신화 제작·강화와 실패 검수 | 확정된 강화 입력·유닛 전투 등록 |
| TASK-UI-02 | 제작·룰렛·강화 패널과 입력 흐름 | 전투 정보·강화 입력·이벤트 |
| TASK-DATA-02 협업 | 경제 도메인 필드 요구·소비·검수 | A가 관리하는 공통 구조·데이터 계약 |

세부 범위와 용어는 해당 명세와 작업 보드로 재확인한다. 미확인 재료 교환은 구현을 확정하지 않는다. 튜토리얼·저장·설정·아트·성능의 후속 계획 역할은 아래 날짜 계획을 따른다.

후속 계획 역할은 [개발 계획서](../../../docs/production/DEVELOPMENT_PLAN.md)에 반영했다. B는 안내/설정·로컬 저장·맵/UI 에셋도 주관한다. 실제 담당·착수·상세 수업은 별도로 기록한다.

## 수업 제작 기준

[수업 양식](../../templates/LESSON.md)으로 목표·시작/완료 SHA·코드·Unreal 설정·실패 재현·상대 전달물을 남긴다. 참고 시작점은 참고 이전 통합본, 실제 시작점은 개발자가 만든 이전 통합본이다. 단계 통합 후 이전 경제·보드·입력 기능의 회귀도 확인한다.

확정되지 않은 후속 담당은 [작업 보드](../../../docs/production/BOARD.md)에서 배정한 뒤 반영한다.
