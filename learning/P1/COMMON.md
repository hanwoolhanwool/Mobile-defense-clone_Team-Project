**단계별 최신 기준:** [로드맵](../../docs/production/ROADMAP.md#phase-plan) · [계획/구현 차이](../../docs/production/PHASE_ALIGNMENT.md). 새 규칙을 검증한 P0에서 시작한다. 룰렛·신화·강화·스킬 확장과 사냥/미션/통계/불멸/2배속 후보는 로드맵의 TASK 연결에 따라 세분화한다. 후보 범위를 자동 확정하지 않으며, 후속 10배수 보스·즉시 한도 패배·경로·해상도 회귀를 완료 조건에 포함한다.

## 진입 조건

| 확인 항목 | 현재 상태 | 착수 시 남길 기록 |
|---|---|---|
| 이전 참고 P0 완료 | 미검증 | 참고 통합 SHA·실행 증거 |
| 이전 실제 P0 완료 | 미검증 | 실제 통합 SHA·실행 증거 |
| 이번 범위·역할 | 일부만 배정 | 정식 TASK·A/B 담당·리뷰 담당 |
| 공통 API·데이터 변경 | 미확정 | 전후 계약·양쪽 적용 순서·호환성 |
| 제공 코드·직접 작성 범위 | 미확정 | 단계별 파일·시작 조건 |
| Unreal 에셋·설정 영향 | 미검증 | 부모·참조·설정 변경과 재검수 범위 |

[역할 기준](../../docs/production/TEAM_ROLES.md)과 [공통 구현 설계](../../docs/technical/IMPLEMENTATION_SHARED.md)를 먼저 확인한다. 경제에서 확정한 강화 입력을 전투에서 소비하는 경계처럼 양쪽에 걸친 변경은 계약부터 합의한다.

## 수업 작성 순서

이전 단계 재현 확인 → 범위/역할 확정 → 최소 API 교환 → 작은 기능 구현/통합 → 전체 회귀 검수 순서로 준비한다. 자세한 설명에는 [수업 양식](../templates/LESSON.md)을 사용한다. 미배정 작업은 담당과 선행 조건을 정한 뒤 A/B 목차에 추가한다.
