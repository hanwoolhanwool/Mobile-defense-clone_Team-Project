# P1 · A 개발자 학습 경로

**단계별 최신 기준:** [로드맵](../../../docs/production/ROADMAP.md#phase-plan) · [계획/구현 차이](../../../docs/production/PHASE_ALIGNMENT.md). 새 규칙을 검증한 P0에서 시작한다. 룰렛·신화·강화·스킬 확장과 사냥/미션/통계/불멸/2배속 후보는 로드맵의 TASK 연결에 따라 세분화한다. 후보 범위를 자동 확정하지 않으며, 후속 10배수 보스·즉시 한도 패배·경로·해상도 회귀를 완료 조건에 포함한다.

**참고 제작: Planned / 실제 개발: Planned.** 상세 수업·구현·설정 캡처·검증 기록은 아직 없다.

**단계별 실행 안내:** [A 개발 문서](../../../docs/production/DEVELOPMENT_A.md)의 P1 작업·주별 산출물·검수 기준을 상세 수업 작성에 사용한다. 실제 수업/구현 완료 상태는 별도로 기록한다.

## 현재 연결할 범위

[A 구현 설계](../../../docs/technical/IMPLEMENTATION_A.md)의 P1 후속 범위를 따른다.

| 상위 작업 | 제작할 학습 내용 | B와 연결할 경계 |
|---|---|---|
| TASK-DATA-02 | 확장 Row·전투 데이터·참조 검증 | 경제·UI가 소비하는 데이터 계약 |
| TASK-COMBAT-02 | 희귀 고유 스킬·효과·중첩/만료·전투 검수 | B가 확정한 강화 입력 |
| TASK-WAVE-02 | 확정한 웨이브·적/보스 확장·10배수 보스·결과 검수(기존 30웨이브는 후보) | 보상·HUD·공용 결과 |

이 표는 기존 배정의 연결이며 각 수업의 구체적인 순서·완료를 확정하지 않는다. 전투 규칙의 원작 검증과 선행 조건을 확인해 세분화한다.

후속 계획 역할은 [개발 계획서](../../../docs/production/DEVELOPMENT_PLAN.md)에 반영했다. A는 보조 봇·캐릭터/적/보스 에셋·성능도 주관한다. 실제 담당·착수·상세 수업은 별도로 기록한다.

## 수업 제작 기준

[수업 양식](../../templates/LESSON.md)으로 목표·시작/완료 SHA·코드·Unreal 설정·실패 재현·상대 전달물을 남긴다. 참고 시작점은 참고 이전 통합본, 실제 시작점은 개발자가 만든 이전 통합본이다. 단계 통합 후 이전 전투·웨이브 기능의 회귀도 확인한다.

확정되지 않은 후속 담당은 [작업 보드](../../../docs/production/BOARD.md)에서 배정한 뒤 반영한다.
