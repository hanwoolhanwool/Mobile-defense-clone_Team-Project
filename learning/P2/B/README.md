## 현재 연결할 범위

[개발 계획서](../../../docs/production/DEVELOPMENT_PLAN.md)에 P2 계획 역할을 편성했다. 실제 담당자·서비스 사양·상세 수업과 구현은 별도 확인한다.

| 수업을 추가하기 전 결정할 내용 | 현재 상태 |
|---|---|
| B의 상위 TASK·완료 조건 | TASK-ACCOUNT-01·ROOM-01 주관, 보상/복귀 UI·미니게임 1종 가배정. 보드/날짜 계획 참조 |
| A·서비스 코드와의 API/데이터 경계 | 미정 |
| 경제·입력·HUD와 서비스 연결 범위 | 미정 |
| 정상·실패·재시도 등 해당 QA 범위 | 정식 범위 확정 후 작성 |

## 수업 제작 기준

[수업 양식](../../templates/LESSON.md)으로 목표·시작/완료 SHA·코드·Unreal 설정·실패 재현·상대 전달물을 남긴다. 참고 시작점은 참고 이전 통합본, 실제 시작점은 개발자가 만든 이전 통합본이다. 단계 통합 후 이전 경제·보드·입력 기능의 회귀도 확인한다.

확정되지 않은 후속 담당은 [작업 보드](../../../docs/production/BOARD.md)에서 배정한 뒤 반영한다.
