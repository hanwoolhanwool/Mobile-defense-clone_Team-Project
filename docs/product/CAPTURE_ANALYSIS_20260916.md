두 구역의 **형태는 확인**했지만 칸 선이 없어 정확한 칸 수는 이번 사진만으로 확정하지 않았다. 당시 기존 과거 자료의 6열×3행을 후보로 두었고, 후속 사용자 지시 DEC-039로 프로젝트의 플레이어당 가로 6칸×세로 3칸을 확정했다. 사진 관찰과 사용자 결정을 구분한다. `0/26`은 인구 표시이며 26칸이라는 뜻이 아니다.

좌측 상단·좌측 하단 생성 및 중앙 왼쪽→오른쪽 합류는 **사용자 요구 DEC-030/031**을 적용한다. 사진 자체는 통로 모양의 근거다. 이후 사용자가 중앙 통과 후 각 몬스터가 자기 생성 보드를 중심으로 순환한다고 명확히 했으므로 DEC-033으로 복귀 규칙을 확정했다. 근거는 사진에서 추정한 이동이 아닌 사용자 지시다.

## 후속 사용자 확정 — 몬스터 수와 보스

DEC-034: 사진 상단 카운터의 최대 수에 도달하면 게임 오버다. 보스는 10웨이브마다 출현하며 제한 시간 안에 처치하지 못하면 패배한다. 이 규칙은 사용자 설명으로 확정했고 정지 사진에서 계산해 낸 값으로 표시하지 않는다. 기존 3초 과밀 유예는 폐기한다. 최대 수의 기본값·보정, 보스 제한 초수·수량·상단 카운터 포함 여부는 추가 확인한다. 선택형 사냥의 01:00은 웨이브 보스 제한 시간과 구분한다.

## 추가 관찰이 필요한 최소 항목

1. **보드 조작**: 빈 칸 전체 위치, 1/2/3개 스택 이동, 이동 시 수용량 초과, 다른 종류 교환, 분산 합성, 등급별 판매 보상, 복수 여유 뭉치 우선순위와 빈칸 없는 무작위 소환 정책. 소환 시 동일 뭉치 추가·최대 3·초과 시 새 뭉치·선택 UI는 DEC-037로 확정했다. 손가락 입력과 전후 배치·재화가 함께 보이는 연속 기록이 필요하다.
2. **전투 규칙 세부값**: 생성 주기, 최대 수의 기본값/계정 보정, 보스 제한 초수·수량·집계 대상, 최종 승리·동시 시각 경계. 상한 도달 패배·10배수 웨이브 보스·시간초과 패배는 사용자 DEC-034로 확정했다. 중앙 이후 각자 보드로 복귀·순환하는 규칙은 사용자 DEC-033으로 확정되었으므로 추가 원작 관찰의 선행 조건에서 제외한다. 정지 사진만으로 초 단위 상수를 계산하지 않는다.
3. **경제 기준**: 동일 계정의 초기 영웅·유물·펫·버프와 난이도를 기록한 뒤 연속 소환 비용·무료 횟수·등급별 판매·강화 전후를 비교한다. 숨은 확률은 작은 표본으로 확정하지 않는다.

위 정보가 없어도 전장 구도, UI 기능 지도, 서버 권한과 데이터 분리, A/B 작업 계약을 구체화할 수 있다. 불명확한 숫자를 원작 확정값으로 만들 필요는 없다.
