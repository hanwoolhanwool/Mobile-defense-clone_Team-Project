# G2 독립 리뷰 기대값

상태: **G2 범위의 최종 독립 리뷰 완료**. 제품 기준 `5baa96059e94a142d45206290010b373cf39ea19`의 새 출발점 재현56파일 일치·Editor Pass·Unreal 자동화39개 무경고 Pass 이후, 제품 코드가 동일한 `ae6be1b0b06ed733425e01632a341fb4db4cad59`의 검증 보강을 적용해 명령12개 무경고 Pass와 Engine 터치 드래그 포함20단계 GPU host213/client57개 Pass를 확인했다. 전체 교환·전설 거절·등급별 판매·준비 격리/ID·중복 보상 보완도 통과했다. 각 항목의 정적/실제/미검증 및 G3/G4 의존성은 [최종 리뷰 매트릭스](FINAL_REVIEW.md)에 구분하며24개 모든 조합을 일괄 실행했다고 표시하지 않는다. 독립 기대값 작성 당시 공통 계약은 `803c52e37924baae0d5297571fe5a14b8a02121a`, Schema2/Rules0.3.0이다. 원래 입력·기대값은 실행 결과에 맞춰 바꾸지 않았고 G1의 이전 Pass도 G2 증거로 재사용하지 않았다.

수치 주입·정지 적·임의 피해·실패 주입은 명시적 fixture로 실행하고 실제 플레이 증거와 구분한다. 특히 정상 P0 불변식(16종·종류별 여유 뭉치 최대1·인구20)에서18칸 완전 점유는 도달할 수 없어, 빈칸 없는 수용 방어 검사는 격리 fixture임을 기록한다. G2-R18의 방어 보정은 P0 기본 공격만 검사하며 P1 효과를 켜지 않는다.

각 ID의 `검토 SHA / 파일·함수 / 실제 입력·결과 / 증거 / 미검증`은 최종 리뷰 매트릭스에 기록했다. 결함은 `파일·함수·재현 상황·영향·수정 방향`으로 보고하고 차단 결함은 수정·재검증 전 다음 게이트로 넘기지 않는다. 문서/데이터 정적 검사, Unreal 컴파일, NullRHI 자동화, 실제 두 프로세스, 패키지, Android 결과를 각각 기록한다. 실제 첫 소환→배치→타격→사망→양쪽 보상과 이동·합성·판매·보충 연결은 내부 fixture만으로 통과 처리하지 않는다.
