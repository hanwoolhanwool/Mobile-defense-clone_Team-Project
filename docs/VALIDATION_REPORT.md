# 설계 데이터 검증 결과

RulesVersion: 0.3.0 · SchemaVersion: 2

결과: **통과** · 검사 2689항목 · 실패 0개

정적 데이터·참조·수식·확률 구간·배치 및 경로 계약을 검증한다. UE 임포트·실행·명령 처리·밸런스·모바일·네트워크 검수는 수행하지 않았다. 검사 수를 독립된 게임 테스트 수로 해석하지 않는다.

## 범위

- P0 일반~전설 각 4종, 16종 기본 공격. 명칭/외형은 임시, 신화 4행·고유 스킬 16행·레시피 4행은 컨셉 대기 비활성 자료.
- 개인 6×3칸·인구 20·칸당 3, 기본 일반 적 한도 100. 113/26은 별도 시험 프로필.
- 두 경로가 중앙을 같은 방향으로 통과하고 자기 보드로 복귀. 임시 140cm 셀과 길 폭, 사거리 1.25/2.5/3.5칸.
- 80웨이브 표에서 P0는 1~10만 사용. 일반 20초·진영별 20마리·1초 간격, 보스 진영별 1마리·60초 제한, 양쪽 완료 후 2초.
- 소환 확률 11단계 및 룰렛 3종의 10,000개 정수 구간 전수 분포·경계. 보장 기능 없음.
- 유료 소환 비용 20+2n, 일반 판매 floor(다음 유료 소환 비용×0.5), 웨이브 진입/종료 기본 보상 0.
- 강화 4종 비용/상한/확률표 연결, 스킬/신화 비활성, 던전 복귀 원자성·미션 비반복 계약.
