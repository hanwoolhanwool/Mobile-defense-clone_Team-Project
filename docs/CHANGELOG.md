# 기획 변경 이력

[기획 허브](README.md) · 현재 문서 체계 0.2 · 데이터 RulesVersion 0.1.0

정렬은 최근 변경부터 합니다. 이 문서에는 의도·규칙·구조 변경을 요약하고, 세부 차이는 Git으로 추적합니다. 과거 대화의 정확한 처리 시각을 새로 만들어 기록하지 않습니다.

## CHG-0031 · 2026-09-14 · main 보호·코드 규약 현황 확인

- DEC-024에 따라 main의 PR 필수·documentation 필수 검사·strict·관리자 적용·강제 push/삭제 금지·대화 해소를 설정하고 API로 재조회.
- 리뷰 담당자 미배정 상태를 반영해 필수 승인 0명으로 시작. 필수 CI와 사람의 리뷰를 구분.
- 코드 작성 규약은 별도 문서가 없고, 커밋 규약과 기술 문서의 일부 규칙만 있음을 확인. [관리 방식](WORKFLOW.md)에 보유 현황을 기록했으며 코드 규약을 새로 채택한 것은 아님.
- [RUN-20260914-03](production/TEST_RUNS.md)에 실제 보호 설정과 조사 범위를 기록. 게임 작업 상태는 유지.
