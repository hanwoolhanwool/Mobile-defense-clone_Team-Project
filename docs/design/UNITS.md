# 수호자·스킬 콘텐츠

[기획 허브](../README.md) · [작업 보드](../production/BOARD.md) · [검수 기준](../BACKLOG_QA.md)

문서 상태와 담당자는 위 메타데이터를 기준으로 한다. 사용자 확정 조건은 결정 기록을 따른다. 나머지 내용은 프로토타입용 설계안이다. 기획 작성 상태와 실제 구현 상태는 별도로 관리한다.

이 파일이 해당 기능의 편집 원본이다. 기존 GDD 장 번호를 유지해 이전 기획과 대응시킨다. 수치·데이터 타입은 허브의 원본 구분표를 따라 함께 변경한다.

## 9. 수호자 20종 및 스킬

DEC-019의 P0에는 C01~C04·R01~R04의 기본 공격·능력치만 적용한다. 아래 희귀 스킬 4종은 P1에서 구현·검증하며 P0에서는 공격 횟수·시간·오라 조건을 만족해도 발동하지 않는다. 전체 게임용 스킬 데이터·능력치는 유지하고 P0 선택 패널에는 비활성 고유 스킬 설명을 노출하지 않는다. P0 성능·재미 결과를 스킬 포함 역할별 밸런스 검증으로 해석하지 않는다.

### 9.2 스킬 해석 세부

- 공격 횟수형은 **유효 표적에 수행한 기본 공격**만 센다. 추가탄·연쇄·DoT는 카운터를 증가시키지 않는다. 카운터가 N이 되면 발동하고 0으로 초기화한다.
- 추가탄 R02는 현재 표적이 살아 있으면 다시 타격하며 죽었으면 사거리 내 새 표적 하나를 찾는다. 없으면 소멸한다.
- 초 단위 스킬은 생성 뒤 전체 쿨다운이 지나야 처음 준비된다. 준비됐지만 표적이 없으면 준비 상태를 유지하고 유효 표적 발견 시 발동한다. 공격속도는 주기를 줄이지 않는다.
- 광역 중심은 현재 유효 표적의 위치다. 기본 공격과 독립적으로 대상을 찾는다. 둔화 전용 E01/L02는 직접 피해가 0이다.
- 연쇄 계수는 각 대상에 동일 적용한다. E02/L03은 기본 공격과 별도의 추가 스킬 타격이며 첫 대상에도 연쇄 피해가 한 번 들어간다.
- 오라는 최대 중첩 규칙을 사용한다. 악사 여러 명이나 설계사·설계자를 함께 놓아도 공격력 버프는 30%까지다.

### 9.3 신화 상세

아래 신화·수치는 기존 자체 설계 초안이며 DEC-021/DEC-022의 원작 대조가 필요하다. 화상은 [전투 명세 8.3.1](BATTLE.md)의 종료 경계를 따른다. 재적용·억제·사망·전투 종료가 없으면 적용 후 1·2·3초에 총 3틱이며, 3초 시점의 마지막 틱 이후 제거한다.

| 신화 | 발동 | 정확한 효과 | 3D 연출 |
|---|---|---|---|
| 태양 용광로 | 5초 | 현재 표적 중심 반경 240cm, 최대 10명에게 마법 계수 2.2. 맞은 대상에 3초 화상: 1초마다 계수 0.35, 총 3틱 | 뚜껑 개방 → 주황 열기 → 바닥 고리 |
| 폭풍 지휘자 | 기본 공격 3회 | 계수 1 물리 연쇄 최대 5명. 최초 대상이 보스면 그 보스에게 추가 계수 1.5 한 번 | 지휘봉 회전, 얇은 번개 연결 |
| 겨울의 파수꾼 | 4초 | 반경 240cm 최대 10명, 마법 계수 0.8, 50% 둔화 3초, 방어력 -30 3초 | 낮은 얼음 파동, 보스도 보이는 지면 장식 |
| 별빛 설계자 | 상시 | 반경 600cm 아군에게 공격력 +30%, 공격속도 +15%. 자신 포함, 팀 구분 없음 | 작은 별 궤도, 버프 받는 받침대 아이콘 |

### 9.4 역할과 합성 선택

일반 3개보다 희귀 1개의 기본 DPS가 약간 높도록 시작하지만, 결과 사거리·역할이 바뀌므로 언제나 무조건 합성하는 최적해가 되지 않도록 검사한다. 희귀 지원 3개를 합쳐 딜러 영웅을 얻는 상황과 둔화 유닛을 소모해 전설을 얻는 상황을 테스트한다.

재료 추적은 레시피 하나를 고정하는 편의 기능이다. 전체 자동 합성, 자동 제작, 결과 재추첨은 MVP에서 제공하지 않는다.
