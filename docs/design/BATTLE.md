# 전투·웨이브·적·승패

[기획 허브](../README.md) · [작업 보드](../production/BOARD.md) · [검수 기준](../BACKLOG_QA.md)

문서 상태와 담당자는 위 메타데이터를 기준으로 한다. 사용자 확정 조건은 결정 기록을 따른다. 나머지 내용은 프로토타입용 설계안이다. 기획 작성 상태와 실제 구현 상태는 별도로 관리한다.

이 파일이 해당 기능의 편집 원본이다. 기존 GDD 장 번호를 유지해 이전 기획과 대응시킨다. 수치·데이터 타입은 허브의 원본 구분표를 따라 함께 변경한다.

## 5. 시간·웨이브·승패 판정

DEC-021/DEC-022에 따라 게임 규칙은 [Android 2.0.11 보통 모드 대조 기록](../product/ORIGINAL_REFERENCE.md)을 우선한다. 아래 화상·유닛 수치와 중첩 방식은 기존 자체 설계 초안이며 원작에서 확인한 규칙이 아니다. 이번 정리는 그 초안의 예약 피해와 만료 처리 간 충돌을 해소하는 기술 명세이며, 원작 확인 없이 해당 스킬의 구현을 확정하지 않는다.

DEC-019의 P0는 FinalWave=10, 일반 4종·희귀 4종의 기본 공격과 능력치 차이만 사용한다. 아래 전체 전투 명세 중 강화·고유 스킬·상태이상·오라는 P1 범위이며 P0에서 발동하지 않는다. Preparing의 강화 구매도 P0에서는 거절한다. 승패·과밀·마감 경계 규칙은 P0에도 적용하되 최종 웨이브를 10으로 치환한다.

### 5.1 상태 전이

| 상태 | 진입 | 종료 |
|---|---|---|
| Loading | 방 인원 2명 또는 연습+봇 확정 | 두 참가자 준비 완료, 30초 초과 시 방 복귀 |
| Preparing | 전장 생성 완료 | 10초 경과 |
| Running | 웨이브 1 시작 | 승패 또는 서버 중단 |
| Result | 결과 확정, 게임 변경 명령 거절 | 각자 로비/다시 하기 선택 |
| Aborted | 서버 종료·필수 데이터 오류 | 오류 사유를 표시하고 로비로 이동 |

Preparing에서는 골드 소환·배치·판매·강화가 가능하다. 전투와 시간 보상은 Running에서 시작한다. 온라인 전투 중 메뉴를 열어도 게임은 멈추지 않는다. 연습 모드에서만 일시정지를 허용한다.

### 5.2 시간 규칙

웨이브 w 시작 시각=`RunStartTime+30*(w-1)`초. 기본 30초마다 다음 웨이브가 시작되며, 이전 웨이브 적이 남아 있어도 계속된다. 일반 웨이브는 시작 후 0~20초에 표에 정해진 적을 분산 생성한다. 모든 시각은 서버 전투 시간을 따른다.

보스 웨이브 10/20/30은 새 일반 적을 생성하지 않고 시작 시 보스 2마리를 생성한다. 기존 일반 적은 남는다. 보스 둘을 30초 안에 모두 처치해야 한다. 10/20웨이브 보스를 일찍 잡아도 다음 웨이브 시작은 앞당기지 않는다.

### 5.3 승패

| 판정 | 정확한 규칙 |
|---|---|
| 과밀 패배 | 살아 있는 적이 100마리 이상인 상태가 연속 3.0초 지속 |
| 과밀 해제 | 99마리 이하가 된 틱에 누적 시간을 0으로 초기화 |
| 보스 패배 | 해당 보스 웨이브 마감 시각에 보스가 한 마리라도 생존 |
| 최종 패배 | 30웨이브 마감 시각에 일반 적 또는 보스가 한 마리라도 생존 |
| 승리 | 30웨이브 생성이 끝났고 적 전체가 0이며 패배가 먼저 확정되지 않음 |
| 중단 | 서버가 복구 불가능하게 종료되거나 필수 데이터 오류 발생 |

아군 수호자는 적에게 공격받지 않으며 HP·사망·부활을 갖지 않는다. 기지 HP나 누적 탈출 횟수는 사용하지 않는다. 패배 UI는 `적 과밀`, `보스 처치 시간 초과`, `최종 잔여 적` 중 우선 판정된 한 원인을 표시한다.

### 5.4 같은 틱의 처리 순서

20Hz 논리 스텝마다 입력 검증·명령 적용 → 스폰 → 이동·상태 만료 → 예정 DoT·화상 만료 정리 → 예정 공격/스킬 → 피해·사망 정리 → 과밀 갱신 → 마감 패배 검사 → 승리 검사 → 웨이브 종료 보상 순서로 처리한다. 화상은 8.3.1에 따라 만료 시각의 예약 틱을 처리한 뒤 제거한다. 다른 상태의 지속시간을 연장하는 규칙은 아니다. 시각 경계를 넘긴 스텝에서는 마감 시각 이하에 예약된 타격만 먼저 처리하고 마감을 판정한다. 마감 이후 타격으로 소급 승리하지 않는다.

동일 시각의 적 사망은 먼저 반영되므로 마감 시각에 정확히 사망한 마지막 보스는 성공이다. 웨이브 경계에서는 이전 웨이브의 마감 이하 이벤트·승패·보상을 먼저 처리하고, 전투가 계속될 때만 다음 웨이브의 같은 시각 스폰을 시작한다. 아직 이전 보스의 실패를 검사하지 않은 상태에서 다음 웨이브 적을 먼저 생성하지 않는다. 이미 Result 상태이면 이후 패킷·타이머·사망 이벤트를 모두 결과에 반영하지 않는다.

## 8. 전투·피해·상태이상

### 8.1 공격 판정

수호자는 고정 칸에서 공격한다. 사거리는 칸 중심과 적 중심 사이의 평면 거리다. 표적 후보는 살아 있고 사거리 안에 있는 적이며, 기본은 `보스 우선`을 끈 `가장 가까운 적`이다. 거리가 같으면 SpawnSerial이 작은 적을 선택한다. 선택 패널에서 보스 우선을 켜면 사거리 내 보스부터 찾고, 없으면 기본 규칙으로 돌아간다.

이미 유효한 표적은 다음 공격까지 유지한다. 공격 시작 시 범위·생존을 검사하고 피해를 즉시 적용한다. 애니메이션과 투사체는 결과 표현이다. 시각 투사체가 다른 적에 닿더라도 추가 피해를 주지 않는다. 장거리 발사체는 0.15초 이내에 닿도록 조정하여 피해가 먼저 들어가는 차이를 줄인다.

초기 생성 시 기본 공격 준비 시간은 0.25초다. 기본 공격과 자동 스킬이 같은 스텝에 준비되면 기본 공격 후 스킬을 처리한다. 상태를 가지는 스킬은 서버의 별도 타이머로 관리하고 AnimNotify를 피해 권한으로 사용하지 않는다.

### 8.2 피해 공식

```text
ATK = BaseAttack * (1 + 0.10*AttackUpgradeLevel) * (1 + StrongestAttackBuff)
AttackInterval = BaseInterval / (1 + 0.05*HasteLevel + StrongestHasteBuff)
AttackInterval 최소값 = 0.25초
Raw = ATK * SkillCoefficient
PhysicalMultiplier = 100 / (100 + max(0, Armor - StrongestArmorBreak))
MagicMultiplier = 1 - clamp(MagicResistance, 0, 0.75)
Final = max(1, round_half_up(Raw * 해당 방어 배율))
```

기본 공격 계수는 1이다. 치명타·회피·속성 상성·관통은 MVP에 없다. DoT도 시전 시점 ATK를 저장하고 각 틱에 대상의 현재 저항을 적용한다. 공격 훈련은 기본 공격과 공격력 계수 스킬 모두에 적용된다. 공격속도 강화는 초 단위 자동 스킬·DoT 간격을 바꾸지 않는다.

예: 공격력 100, 공격 훈련 2, 공격 버프 10%, 물리 계수 1, 방어력 50, 방어 약화 20이면 `round(100*1.2*1.1*100/130)=102` 피해다.

### 8.3 효과 중첩

| 효과 | 기본 처리 | 보스 |
|---|---|---|
| 둔화 | 최대 수치 하나 적용, 다른 원천은 남은 시간 별도 관리, 상한 50% | 적용 강도 상한 25% |
| 기절 | 이동 정지, 중첩은 남은 시간과 새 지속시간 중 큰 값 | 면역 |
| 방어 약화 | 가장 높은 절대 감소 수치 하나, 방어력 최저 0 | 동일 적용 |
| 화상 | SkillId+시전자 기준 관리하되 대상당 가장 강한 1개만 피해 | 동일 적용 |
| 공격력 버프 | 수치가 가장 큰 하나, 자신 포함 사거리 안 아군 | 동일 적용 |
| 공격속도 버프 | 수치가 가장 큰 하나, 자신 포함 사거리 안 아군 | 동일 적용 |

효과는 남은 시간이 끝나면 해제하되 화상의 만료 시각 예약 틱은 8.3.1을 따른다. 강한 효과가 끝나도 아직 살아 있는 약한 효과가 있으면 다시 적용한다. 동일 시전자의 재적용은 지속시간을 갱신하며 즉시 DoT 추가 틱을 발생시키지 않는다. 죽은 대상의 상태와 예약 이벤트는 제거한다.

적은 아군을 때리지 않으므로 기절은 적 이동만 막는다. 적 보스 스킬 주기는 이동 상태와 무관하지만 보스는 기절 면역이다. 지원 오라는 0.25초마다 범위 갱신, 빠져나온 대상에서 즉시 다음 갱신에 제거한다.

### 8.3.1 화상의 마지막 틱과 종료 경계

이 절은 P1 상태이상 실행기의 검수 기준이다. P0에는 화상을 활성화하지 않는다. 화상 강도·동률·재적용의 데이터 해석은 [데이터 명세](../DATA_SCHEMA.md)의 DT_Skills 계약을 따른다.

- 최초 적용 시각을 T라 하면 첫 틱은 `T+DotIntervalSeconds`다. 재적용·다른 원천·사망·전투 종료가 없는 현재 3초 화상은 T+1, T+2, T+3초에 각각 한 번 피해를 주고 제거한다. T 시점의 광역 직접 피해는 이 3틱에 포함하지 않는다.
- 예약 시각이 `ExpireTime`과 같은 틱은 유효하다. 서버 논리 시간으로 예약 시각 순서대로 처리하며, 프레임 지연으로 실행 시각이 늦어졌다는 이유로 유효했던 마지막 틱을 버리지 않는다. `ExpireTime` 이후 예약은 피해를 만들지 않는다. 전투 마감 이후 예약도 5.4에 따라 제외한다.
- 같은 시각의 화상 원천들은 만료 제거 전 상태에서 강도·동률 규칙으로 활성 원천 하나를 결정한다. 해당 시각에 예약이 있는 활성 원천만 피해를 주며, 억제된 원천의 예약 틱도 소비한다. 그 시각의 예약들을 처리한 후 만료 원천을 제거하므로 약한 원천이 같은 시각에 추가 피해를 주지 않는다. 억제 기간의 피해는 나중에 보충하지 않는다.
- 같은 시각에 기존 틱과 스킬의 화상 재적용이 겹치면 기존 틱을 먼저 소비하고 재적용한다. 재적용 자체는 피해를 만들지 않으며 이미 처리한 예약을 다시 등록하지 않는다. 아직 예정된 NextTickTime은 유지한다. 마지막 틱까지 소비해 제거한 원천을 같은 시각 다시 적용하면 첫 예약은 그 시각에서 DotIntervalSeconds 뒤다. 중복 콜백에서도 동일 대상·원천·예약 틱은 한 번만 소비한다.
- 각 피해 직후 대상의 생존을 갱신한다. 사망한 대상의 후속 예약은 취소하고, 풀에서 재사용한 액터에 이전 대상의 예약을 적용하지 않는다. Result 확정 이후에는 남아 있는 예약으로 피해·사망·보상을 추가하지 않는다.

검수 시 적용 시각, 원천, 예약 시각, 만료 시각, 활성/억제 여부, 실제 피해 횟수와 대상 생존 상태를 기록한다. 특히 [QA-DMG-11](../BACKLOG_QA.md#QA-DMG-11)~[QA-DMG-14](../BACKLOG_QA.md#QA-DMG-14)는 구현 후 실행할 항목이며 문서 정적 검사로 통과 처리하지 않는다.

### 8.4 공간 검색·정렬

전장 전체 적 목록을 중앙 관리하고 공간 버킷 또는 경로 구간으로 후보를 줄인다. 광역 타격 대상은 중심과의 거리·SpawnSerial 순서로 제한 수만큼 선택한다. 연쇄는 최초 대상 뒤 이전 타격점 250cm 이내의 가장 가까운 미타격 대상을 고른다. 같은 적을 한 연쇄에서 두 번 때리지 않는다.

## 10. 적·보스·웨이브 구성

### 10.1 일반 적

일반 적 기준 HP=`round_half_up(70*1.12^(w-1))`. 각 적의 최종 HP는 이 기준값에 유형 배율을 곱한 뒤 반올림한다. 속도와 방어는 유형의 고정값이다.

| ID | 이름 | HP 배율 | 속도 cm/s | 물리 방어 | 마법 저항 | 특징 |
|---|---|---:|---:|---:|---:|---|
| N01 | 먼지 인형 | 1.00 | 150 | 0 | 0% | 기준 적 |
| N02 | 질주 팽이 | 0.75 | 220 | 0 | 0% | 사거리 체류 시간 감소 |
| N03 | 철갑 장난감 | 1.60 | 120 | 60 | 0% | 마법·방어 약화 필요 |
| N04 | 절연 인형 | 1.20 | 150 | 0 | 35% | 물리 화력 필요 |

적은 서로 밀거나 충돌하지 않는다. 경로 거리로 이동하고 약간의 옆 오프셋만 시각적으로 부여한다. 적의 시각 크기는 일반 45~65cm, 보스 110~140cm다. 유닛 또는 적의 외형 크기가 사거리·공격 범위를 바꾸지 않는다.

### 10.2 웨이브 수량과 혼합

일반 웨이브는 생성점당 `12+floor((w-1)/3)`마리, 팀 전체는 두 배다. 보스 웨이브는 보스 2마리만 새로 생성한다. 1~3은 N01 100%, 4~9는 N01/N02=75/25%, 11~19는 N01/N02/N03=50/25/25%, 21~29는 네 유형 25%씩이다.

구성 비율은 실제 정수 개체 수로 변환한다. 각 유형의 수량을 내림한 뒤 남는 수를 소수 부분이 큰 유형부터 배정하며 동률은 N01→N04 순서다. 스폰 순서는 유형별 편중을 줄이도록 이미 배정한 수량의 비율이 가장 낮은 유형부터 골라 고정 순서를 만든다. RNG를 사용하지 않는다.

생성점당 K마리는 `t_i=20*i/(K-1)`, i=0..K-1 시점에 생성한다. 두 생성점은 동일 시각·구성이다. 생성점별 잔여 수량과 예약 시각은 웨이브 시작 때 확정한다.

### 10.3 보스

| 웨이브 | 보스 | 각 HP | 속도 | 방어/마저 | 패턴 |
|---:|---|---:|---:|---|---|
| 10 | 고철 골렘 B01 | 6,000 | 100 | 20 / 10% | 별도 능력 없음. 첫 화력 검사 |
| 20 | 폭주 기관장 B02 | 30,000 | 150 | 35 / 15% | 8초마다 3초간 이동속도 1.5배 |
| 30 | 균열 감독관 B03 | 90,000 | 120 | 40 / 20% | 10초마다 4초간 일반 적 전체 속도 +20% |

모든 보스는 기절 면역, 둔화 최대 25%. B02의 속도 폭주는 기본 속도×1.5×(1-둔화) 순서다. B03은 보스 자신과 다른 보스를 가속하지 않으며, 같은 효과 두 개는 겹치지 않는다. 30웨이브 신규 일반 적이 없으므로 B03 패턴은 이전 웨이브 잔여 적을 빨리 정리하도록 유도한다.

보스는 각 생성점에 한 마리씩 나타난다. 상단 UI는 두 체력을 별도 막대로 표시하고 남은 제한 시간 하나를 공유한다. 화면에 한 마리가 가려져도 남은 수와 체력을 확인할 수 있다.

### 10.4 밸런스 기준

기본 적의 한 바퀴 시간은 약 26.7초다. 10웨이브 보스 두 마리는 30초 동안 총 12,000HP, 20은 60,000HP, 30은 180,000HP를 처리해야 한다. 최종 보스의 **저항 적용 후 팀 평균 실효 DPS 하한은 6,000**이며, 준비 시간·사거리 이탈을 포함하면 필요한 보유 화력은 더 높다. 기본 공격 표의 DPS 합계를 클리어 가능 화력으로 그대로 보지 않는다.

검증 시 팀별 DPS, 사거리 내 체류율, 보스에 적중한 피해 비중, 도전 보장 발동 횟수, 전설·신화 완성 시각을 함께 기록한다. 첫 밸런싱은 보스 HP·웨이브 HP 성장률·골드 수입을 순서대로 조정하고, 한 실험에서 모든 변수를 동시에 바꾸지 않는다.
